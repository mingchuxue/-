# 词韵 · 高中英语盲打背词

看中文释义、音标，听发音，凭记忆盲打出英文单词。打对立即进入下一个，在打字中把高中英语词汇记牢。

## 打开方式

- **直接打开**：双击 `index.html`，用 Chrome / Edge / Safari / Firefox 打开即可，无需安装或联网（发音除外）。
- **本地服务器（可选）**：在本目录运行 `npx --yes serve .` 或 `python3 -m http.server`，然后访问提示的地址。
- **部署上线**：本项目是纯静态网站，把整个文件夹上传到任意静态托管（GitHub Pages、Netlify、Vercel、Cloudflare Pages、对象存储等）即可。

首次进入会显示开始界面，点击「开始练习」或按任意键后开始（浏览器要求先有一次点击/按键才允许播放声音）。

每个词条包含：英式 / 美式音标、词性与中文释义、不规则变化（如 go：过去式 went，过去分词 gone）。大部分词条另附例句（例句中的目标词以下划线遮住）、常用短语和助记。

数据覆盖（「高中英语全部词汇」3903 词）：

- 中文释义：100%；释义均带词性：99.8%（其余为少量无词性的复合词）
- 音标：99.9% 至少有一种；英音 99.9%，美音 98.4%
- 例句：93.6%

## 功能

- **盲打练习**：每个字母一个格子，打对的字母依次显示；打错时字母标红并轻微抖动。整词打对后自动进入下一个，不用按回车。
- **不区分大小写**；短语要输入空格，缩写要输入点号（如 `a.m.`）。
- **发音**：每个词出现时自动朗读一次，点击听筒或按 `Ctrl/⌘ + J` 再听一次。英音 / 美音可切换。真人发音来自有道词典在线音频，加载失败或离线时自动改用浏览器自带的语音合成。
- **提示**：按 `Tab` 短暂显示单词，这个词会记为「看过提示」并收进错词本。也可以开启「常显单词」跟着打。
- **两种模式**：释义模式（释义 + 词性 + 音标）；默写模式（隐藏释义，只听发音、看音标，打完后显示释义）。
- **章节**：按字母顺序或乱序（固定随机种子，可重新打乱）分章，每章 10 / 20 / 50 词可调。章节面板显示每章完成情况和正确率，可预览本章单词。
- **每词重复**：每个词可连续打 1 / 3 / 5 遍，加深记忆。
- **输错处理**（可选）：标红并撤回（默认，像金山打字一样只撤回错字）/ 整词重打 / 保留错字，需要退格删除。
- **实时统计**：用时（只计算实际打字时间）、词/分、正确率、本章进度。
- **章节小结**：正确率、速度、用时、出错词。可以重练本章、只练本章错词，或进入下一章。
- **错词本**：打错、看过提示或跳过的词自动收录，可按最近、错误次数或字母排序。在错词练习中连续 3 次一次打对会自动移出，也可以手动标记「已掌握」。
- **进度保存**：当前词书、章节、位置，每个词的练习次数、错误次数、提示次数和掌握标记都保存在本机浏览器（localStorage）里，可在设置中导出 / 导入备份。
- **手机可用**：点击卡片会唤起键盘；以电脑键盘为主要使用方式。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 字母 / 空格 / 符号 | 输入 |
| `Backspace` | 删除上一个字母 |
| `Tab` | 短暂显示单词（记为看过提示） |
| `Ctrl/⌘ + J` | 再次朗读 |
| `Ctrl + →` | 跳过当前词（收进错词本） |
| `Ctrl + ←` | 回到上一个词 |
| `Ctrl + D` | 切换默写模式 |
| `Ctrl + M` | 标记 / 取消标记已掌握 |
| `Esc` | 暂停 / 继续；关闭面板 |
| `?` | 快捷键帮助 |
| 小结界面 `Enter` / `R` / `M` | 下一章 / 重练 / 练习本章错词 |

### 处理说明

1. 以高考 3500 词表为主体，并入高中词汇书中的其余单词。去掉明显的错误词条，修正写法（如 `gettogether` → `get-together`）。
2. 拆分「原形 过去式 过去分词」「单数 复数」「原级 比较级 最高级」写法，只保留原形作为练习词，变化形式写在注释里；`exam = examination`、`grey / gray` 这类写法改为「同 / 亦作」注释。
3. 释义优先采用有道词书里带词性的结构化释义，按考纲词表里的词性排序筛选，去掉人名音译、俚语等生僻义项；没有结构化释义时，再解析考纲词表里的释义。
4. 词性统一写成 n. / v. / vt. / vi. / adj. / adv. / prep. / conj. / pron. / num. / art. / int. / aux. / abbr.，短语标为「词组」。
5. 音标统一使用 ˈ ˌ ː 符号。缺音标的复合词按组成词拼合（如 bus stop），全大写缩写按字母读音生成。

重新构建：把上述原始数据放进 `raw/`（扩展词书放在 `raw/extra/`），或者设置环境变量 `CIYUN_RAW` 指向原始数据目录，然后运行 `python3 tools/build_data.py`。

## 已知限制

- 真人发音需要联网访问有道词典；离线或被拦截时改用浏览器自带的语音合成，音色因系统而异。
- 极少数词没有美音（约 1.6%）或英音（4 个），页面只显示已有的那一个。
- 词库来自开源词表，个别释义或例句可能与教材表述不同。
- 练习记录只保存在当前浏览器；换设备或清理浏览器数据前，请先在设置里导出备份。
